# Calculadora_Juros_Simples_E_Composto_WindowsForms
Uma calculadora com duas telas, uma para juros simples e outra para compostos, para que o usuário possa visualizar na prática a diferença entre ambos

## ✦ Sobre
Projeto pessoal realizado como meio de juntar duas matérias do curso de Análise e Desnvolvimento de Sistemas: Programação Orientada a Objetos(POO) e Matemática Financeira, criando um aplicativo no Windows Forms para calcular e comparar Juros Simples e Compostos
